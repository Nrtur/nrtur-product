# Decisions

Owner decisions that shape the product, with dates. One file per topic or period. Each decision says **what** was decided and, where it is not obvious, **why**.

A decision is changed by adding a new dated entry that supersedes the old one. The old one is never edited away; it gets marked `superseded by …` so the history stays readable.
